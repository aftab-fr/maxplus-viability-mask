# Max-plus viability masks for safe and explainable scheduling

Code, data and trained agents for the article
*"Max-Plus Viability Masks for Safe and Explainable Reinforcement Learning Scheduling of a Production Line in a PV-Powered Factory Microgrid"*
(M. A. Uddin, J. Gaber, R. Hasan; revised version submitted to *Results in Engineering*).
Repository: https://github.com/aftab-fr/maxplus-viability-mask

Every table and figure of the article is regenerated by the scripts below; no number is typed by hand
(`make_tables.py` and `make_rev_tables.py` write the LaTeX macros and tables).

## Contents
| path | content |
|---|---|
| `maxplus.py` | max-plus algebra, serial-line model, viability test, critical path |
| `factory_env.py` | Gymnasium environment (mask / shield / penalty; forecast errors; delays; measurement noise; extended tariffs) |
| `baselines.py` | enumeration of feasible schedules, fixed rules, best block, EMPC, oracle |
| `explain.py`, `explain_stats.py`, `explain_audit.py` | model-grounded explanations and their audit |
| `train_ppo.py` | training of one agent (variant, seed, penalty, tariff, hyperparameters) |
| `evaluate.py` | main evaluation (all methods, years, forecast errors) and tightened deadlines |
| `stats_rev.py` | hierarchical block bootstrap, effect sizes |
| `robustness.py`, `robust_ext.py` | processing delays within and beyond the assumed bounds, measurement noise |
| `forecast_rev.py`, `fetch_forecast.py` | real TSO day-ahead forecast errors, AR(1) sensitivity, intraday updates |
| `costmodel_rev.py` | network tariff, demand charge, export remuneration, battery |
| `policy_agnostic.py` | the mask applied to random, rule-based, stale-plan, EMPC and RL policies |
| `rev_eval_extra.py` | tuning (incl. 2021 validation), penalty sweep, model-free agents, per-variant tuning, tariff retraining |
| `scale_env.py`, `scale_cpsat.py`, `scale_run.py` | larger instance (5 jobs, 15-min epochs) with exact CP-SAT EMPC |
| `verify_general.py`, `test_maxplus.py` | verification of the mask (case study and generalized random instances) |
| `figures.py`, `fig_explain.py`, `fig_rev.py` | figures |
| `data/` | PVGIS-SARAH3 PV (simulated), French day-ahead prices, TSO day-ahead solar forecasts and actuals, merged hourly files |
| `runs/` | trained agents (`model.zip`), training metadata and per-episode training logs (`episodes.csv.gz`) |
| `results/` | evaluation outputs (`*.json`, `*.csv.gz`) |

## Reproduce
```bash
pip install -r requirements.txt          # Python 3.13
bash unpack.sh                           # decompress results/ and training logs
python test_maxplus.py                   # verification of the mask
python verify_general.py                 # generalized verification (Remark 2)
# optional: retrain (about 10 min per agent on one CPU core)
python train_ppo.py --variant mask --seed 0
# evaluation, analyses, figures and LaTeX tables
bash run_revision_pipeline.sh
```
Data can be re-downloaded with `fetch_data.py --year Y --real-prices` and `fetch_forecast.py`.
